# 04-technical — Tài liệu kỹ thuật

Kiến trúc hệ thống, Architecture Decision Records (ADR), đặc tả API, sơ đồ dữ liệu.

Thư mục này gộp chung 2 phần thường được tách riêng:
- **AI knowledge base** (system prompt, ngữ cảnh RAG, quy tắc hành vi agent)
- **Key/secret metadata** — xem [`keys.md`](./keys.md)

Tách lại thành thư mục riêng khi lượng tài liệu đủ lớn để cần quản lý độc lập.
