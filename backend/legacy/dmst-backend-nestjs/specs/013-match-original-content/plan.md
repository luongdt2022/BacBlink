# Implementation Plan: Match on Original Content Only

**Branch**: `013-match-original-content` | **Date**: 2026-05-25 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `/specs/013-match-original-content/spec.md`

## Summary

Decouple the matching system from the beautification feature. All query vectors for `compute-matches`, `findMatchingChallenges`, and the `backfill-matches` script will use original `title` + `content` instead of `aiProcessTitle` + `aiProcessedContent`. The Elasticsearch BM25 query will drop `ai_process_title` from the `should` clause. The guard requiring `aiProcessedContent` before matching is replaced with a guard on `content`. No schema changes, no new dependencies, no new abstractions — pure logic change across 4 targeted edits in 3 files plus one doc update.
