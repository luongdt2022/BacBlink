# Kiểm chứng: nền tảng

Cách chạy tệp này: dựng backend theo [`README.md`](README.md#backend) và xác nhận dấu vân tay của bản đang kiểm trước khi bắt đầu. Phần lớn mục trong tệp này chạy bằng `curl` hoặc script và **không cần frontend**; các mục cần frontend được đánh dấu ở cột Cần. Cơ sở dữ liệu phải rỗng khi bắt đầu, trừ các mục nói rõ cần dữ liệu — với chúng, tạo dữ liệu bằng chính API và ghi lại cách tạo.

Giá trị cột Cần: `curl` (không cần trình duyệt) · `bàn phím` · `di động` · `ADMIN` / `USER` / `khách` · `hai trình duyệt` · `ngoại tuyến` · `mạng chậm` · `token hết hạn` · `v1 đã dừng`. Nghĩa của từng giá trị ở [`README.md`](README.md#thiết-bị-và-điều-kiện).
